# Glossary

Terms are added each week. The week a term was introduced is in brackets.

| Term | Meaning |
|---|---|
| **ALD** (atomic layer deposition) [W1] | Deposits films one atomic layer at a time. Needed for the conformal gate stacks in GAA. |
| **BEOL** (back end of line) [W1] | The metal interconnect layers above the transistors. FEOL is the transistors themselves. |
| **BSPDN** (backside power delivery network) [W1] | Power wiring moved to the back of the wafer. Intel calls it PowerVia; TSMC calls it Super Power Rail. |
| **CFET** [W1] | Complementary FET: an nFET stacked on top of a pFET. Expected after forksheet. |
| **COAG** [W1] | Contact over active gate: placing the gate contact directly over the transistor to save area. |
| **CPP** [W1] | Contacted poly pitch (gate pitch): the distance between neighbouring gates. |
| **DIBL** [W1] | Drain-induced barrier lowering: the drain voltage lowers the source barrier, which raises leakage in short-channel devices. |
| **DTCO** [W1] | Design-technology co-optimisation: tuning the process and design rules together to gain density and PPA. |
| **EUV** [W1] | Extreme ultraviolet (13.5 nm) lithography. ASML is the only supplier. |
| **FinFET** [W1] | A 3D transistor with the gate on three sides of a vertical fin. Used from 22nm to 3nm. |
| **Forksheet** [W1] | Nanosheets with a dielectric wall between n and p devices, so they can sit closer together. |
| **GAA** [W1] | Gate-all-around: the gate fully surrounds the channel (nanosheets or nanowires). |
| **High-k / metal gate (HKMG)** [W1] | A gate dielectric such as HfO₂ with a metal electrode. It replaced SiO₂ and polysilicon. |
| **Inner spacer** [W1] | Dielectric between the gate and source/drain in the gaps between nanosheets. |
| **IR drop** [W1] | Voltage lost across resistive power-grid wires. |
| **MBCFET** [W1] | Samsung's name for its GAA nanosheet transistor. |
| **MMP** [W1] | Minimum metal pitch on the tightest interconnect layers. |
| **MTr/mm²** [W1] | Million transistors per mm², a logic-density measure. |
| **Nanosheet** [W1] | A wide, thin, stacked silicon channel in GAA transistors. |
| **PDK** [W1] | Process design kit: the rules, device models and cell libraries a foundry gives designers. |
| **PPA** [W1] | Power, performance, area: the three main design trade-offs. |
| **RibbonFET** [W1] | Intel's name for its GAA transistor (Intel 20A/18A). |
| **SS** (subthreshold swing) [W1] | The gate voltage needed to change current 10× below threshold. Ideally ~60 mV/dec at 300 K. |
| **Track (cell height)** [W1] | Cell height measured in metal pitches, e.g. a 6T cell = 6 × MMP. |
| **Vt flavours** [W1] | Several threshold voltages (uLVT/LVT/SVT/HVT) offered to trade speed against leakage. |
